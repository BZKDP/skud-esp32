# SKUD на ESP32

Система контроля и управления доступом (СКУД) для офиса/склада: открытие дверей,
учёт проходов по картам и PIN-кодам, просмотр и запись камер.

## Компоненты

- `skud_esp32/` — прошивка ESP32 (Arduino/C++): управление 4-канальным реле
  (маглоки и электрозамки), чтение Wiegand-клавиатуры/считывателя карт, OTA-обновление,
  поллинг сервера и локальные serial-команды для режима моста.
- `server-skud/` — сервер на FastAPI (Python): HTTP-API для устройств и веб-кнопки,
  хранение правил доступа, проксирование видеопотоков (MediaMTX/HLS/WebRTC),
  облачная выгрузка записей и фото в S3-совместимое хранилище (`s3lite.py`),
  серверный счётчик людей (YOLO + ByteTrack), статическая веб-панель.
- `pi-bridge/` — мост на Raspberry Pi: по надёжному Ethernet опрашивает сервер и
  передаёт команды на ESP32 по serial, ретранслирует RTSP-камеру, считает людей.

## Архитектура

Устройство (ESP32 / Pi-мост) обращается к серверу по HTTP (`/api/poll`, `/api/device/access`).
Сервер хранит состояние и правила доступа, принимает кадры камер и отдаёт видео в браузер,
записи камер выгружаются в S3. Доступ к видео — только после входа в веб-панель.

## Настройка

Секреты и адреса берутся из переменных окружения. Скопируйте `.env.example` в `.env`
и заполните: `SKUD_SERVER_URL`, `SKUD_DEVICE_TOKEN`, `SKUD_DOOR_PIN`, `SKUD_ADMIN_PASSWORD`,
`SKUD_CAM_TOKEN`, `SKUD_MTX_PASS`, набор `S3_*`, а для диагностики камер — `CAM_*`.
В скетче ESP32 перед сборкой подставьте `WIFI_SSID`, `WIFI_PASSWORD`, `DEVICE_TOKEN`,
адрес сервера и `OTA_PASSWORD`.

## Прошивка и OTA

Скетч `skud_esp32/skud_esp32.ino` собирается в Arduino IDE/arduino-cli для платы ESP32.
Первая заливка — по USB, дальнейшие обновления — по сети через ArduinoOTA (пароль из `OTA_PASSWORD`).
Флаг `SERIAL_ONLY` переключает автономный режим (Wi-Fi + поллинг) и режим serial-ведомого для Pi-моста.

## Требования

- ESP32, 4-канальный релейный модуль, Wiegand-клавиатура/считыватель, маглоки/электрозамки.
- Python 3.10+ (FastAPI, Uvicorn, ultralytics/opencv для счётчика), MediaMTX для видео.
- Raspberry Pi с Python 3 и pyserial для моста (опционально).
- S3-совместимое хранилище для записей и фото.
